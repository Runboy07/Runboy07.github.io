DDCD

2026

A program that lets Dungeons and Dragon's players create and store characters for their campaigns.

Overview

DDCD was created by me and 2 of my peers for our Intermediate Programming Class. We built a Java client/server program that allows many clients to connect to a server that lets them create and store Dungeons and Dragon's characters in a MySQL database. These characters can then have their data read, updated, and deleted.

My role was developing the front end operations like letting the user input character data for new characters, displaying character data on request, and allowing the user to update character data. Understanding Github was a bit of a challenge near the start as we'd just begun learning how to use it. The databse connection also proved to be an issue as it made troubleshooting hard sometimes.
